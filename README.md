# shyam-homes

Real Estate & Property Consultants web platform for Shyam Homes, Patna, Bihar.

## Features
- Property listings (Buy, Sell, Rent)
- Direct WhatsApp & Phone consultation
- Admin Management Portal (Properties, Leads, Visits, Enquiries)
- Modern UI themed with Gunmetal, Saffron, Moonstone, and Light Blue palette
- Fast Vite + React + Tailwind CSS setup
